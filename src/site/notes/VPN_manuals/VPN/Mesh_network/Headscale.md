**Tailscale** — это сервис с закрытым исходным кодом в части «координатора» (сервера, который говорит устройствам, как найти друг друга). Поэтому официально поставить их родную серверную часть на свой сервер нельзя.

Однако сообщество создало полностью совместимый Open Source аналог, который называется **Headscale**.

### Headscale: свой сервер для Tailscale

Это реализация управляющего сервера Tailscale с открытым исходным кодом.

- **Как это работает:** Вы устанавливаете Headscale на свой VPS (например, на Linux в Docker). Ваши устройства используют официальное приложение Tailscale, но в настройках вы указываете адрес своего сервера вместо стандартного.
    
- **Зачем это нужно:**
    
    - **Полный контроль:** Все данные о вашей сети хранятся только у вас.
        
    - **Никаких ограничений:** В бесплатном тарифе Tailscale есть лимиты на количество устройств и пользователей, в Headscale — всё ограничено только мощностью вашего сервера.
        
    - **Приватность:** Список ваших устройств и их IP-адреса не видит никто, кроме вас.
